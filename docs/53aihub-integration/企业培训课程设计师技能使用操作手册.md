# 企业培训课程设计师技能（Skill）使用操作手册

本手册提供逐步操作指引，完成 `corporate-training-designer` 技能在 xAgent 中的加载、配置与验证。

---

## 准备工作

在开始前，确认以下信息已就绪：

| 项目 | 说明 |
|------|------|
| xAgent 服务地址 | 假设为 `http://<xagent-host>:<port>`，下文用 `{BASE_URL}` 代替 |
| Skill 文件 | `SKILL.md` 已部署到 xAgent 容器的 `~/.xagent/skills/corporate-training-designer/` 目录下 |
| Skill 名称 | `corporate-training-designer`（系统使用目录名作为技能标识） |
| 管理员账号 | 需具备 xAgent 登录权限，用于创建 Agent 和查看技能列表 |

---

## 第一步：确认技能已加载

### 1.1 访问技能管理 API

在浏览器或命令行中查询技能列表：

```
GET {BASE_URL}/api/skills/
```

**curl 示例**：

```bash
curl -X GET "{BASE_URL}/api/skills/" \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>"
```

### 1.2 确认技能存在

在返回的技能列表中，确认能看到以下条目：

```json
{
  "name": "corporate-training-designer",
  "description": "**角色定位**...",
  "tags": ["specialized", "hr"]
}
```

### 1.3 （可选）查看技能详情

```
GET {BASE_URL}/api/skills/corporate-training-designer
```

返回的技能详情包含完整的 `content`（SKILL.md 全文）、`when_to_use`、`execution_flow` 等字段。

### 1.4 （可选）重新加载技能

如果技能文件有更新，可通过 reload 接口重新扫描：

```
POST {BASE_URL}/api/skills/reload
```

## 第二步：创建 xAgent Agent Builder 智能体

### 2.1 打开 Agent Builder 页面

在浏览器中访问：

```
{BASE_URL}/agents
```

或者在左侧导航栏中找到 **Agents**。

### 2.2 点击「创建智能体」

进入智能体创建表单。

### 2.3 填写基本信息

| 字段 | 值 |
|------|-----|
| **Name** | `企业培训课程设计师` |
| **Description** | `专注企业培训体系搭建与课程开发的专家，精通培训需求分析、教学设计方法论、混合式学习方案设计、内训师培养、领导力发展项目以及培训效果评估与持续优化。` |

### 2.4 填写指令（Instructions）

将以下内容粘贴到 Instructions 输入框：

```
你是一位资深企业培训课程设计师，深耕中国企业培训与组织学习领域。

核心工作方式：
1. 以业务结果为导向——所有培训设计从业务问题出发，拒绝"为了培训而培训"
2. 培训目标必须可衡量——用具体行为指标替代模糊描述
3. 尊重成人学习规律——每个学习活动都要回答"学了马上能用在哪里"
4. 内容质量标准——所有案例基于真实业务场景改编
5. 数据驱动优化——每个培训项目必须有评估方案

工作流程：
1. 需求诊断：与业务负责人沟通，分析绩效数据和能力差距，确定可衡量的培训目标
2. 方案设计：选择教学策略，设计课程大纲和学习路径，编制预算
3. 内容开发：访谈业务专家萃取经验，开发课件和评估题库，内部评审试讲
4. 培训实施：训前通知预热、训中互动交付、训后作业与行动计划
5. 效果评估：收集满意度与考核数据，追踪行为改变与业务指标变化，沉淀最佳实践

沟通风格：
- 务实落地，用具体方案替代空洞理论
- 数据说话，用可量化的业务指标评估培训价值
- 用户思维，站在学员角度设计学习体验
```

### 2.5 配置 Skills（关键步骤）

在 **Skills** 字段中添加：

```
corporate-training-designer
```

> **说明**：
> - Skills 字段指定此 Agent 可使用的技能列表。xAgent 会在运行时根据用户任务自动判断是否注入该技能。
> - 技能名称必须与实际加载的技能名完全一致（区分大小写）。
> - 当用户任务涉及培训需求分析、课程设计、讲师培养、领导力发展、新员工培训等内容时，技能会被自动匹配并注入到系统提示词中。
> - 如果用户任务与培训无关（如"帮我写个 Python 脚本"），技能不会被激活，避免干扰。

### 2.6 配置执行模式与模型

| 字段 | 推荐值 | 说明 |
|------|--------|------|
| **Execution Mode** | `balanced` | 平衡速度与质量 |
| **Models** | 使用系统默认或选择 `deepseek-v4-pro` | 需要较强中文理解和指令遵循能力 |

### 2.7 添加建议提示词（Suggested Prompts，可选）

在 **Suggested Prompts** 中添加以下预设提示词，方便快速测试：

- `我需要为公司设计一套新员工入职培训体系，包括90天成长计划和导师制度`
- `帮我设计一个针对中层管理者的领导力发展项目，用行动学习的方式`
- `我要建立企业内训师（TTT）选拔和认证体系，请给出完整方案`
- `我们销售团队新人上手周期太长，帮我分析培训需求并设计方案`
- `请设计一个针对全员的合规培训年度计划，覆盖信息安全、反腐败和数据隐私`

### 2.8 保存智能体

点击「保存」或「创建」按钮。

### 2.9 记录 Agent ID

创建成功后，系统会生成一个 `agent_id`，记录下这个 ID，后续调用时需要使用。

## 第三步：调用智能体执行任务

### 3.1 前端直接使用（推荐）

1. 在 Agents 页面找到刚创建的「企业培训课程设计师」
2. 点击进入对话界面
3. 输入培训相关任务，例如：

   ```
   我们公司是一家300人的AI技术企业，研发人员占60%。
   目前遇到的问题是：新人入职后平均要3个月才能独立上手项目，
   PM团队普遍缺乏项目管理专业能力。
   请帮我设计一套针对性的培训方案。
   ```

4. 系统会自动匹配 `corporate-training-designer` 技能，并将完整的企业培训领域知识注入到 Agent 的上下文中
5. Agent 将按照培训课程设计专家的角色和专业方法论进行回复

### 3.2 API 调用方式

**请求方式**：`POST`

**请求地址**：`{BASE_URL}/api/chat/task/create`

**请求体**：

```json
{
  "title": "新员工培训体系设计",
  "description": "为我们公司设计一套新员工入职培训体系，包括90天成长计划、导师制度和试用期评估标准。公司背景：300人AI技术企业，研发人员占60%。",
  "agent_id": "<第二步记录的 agent_id>",
  "execution_mode": "balanced",
  "sync": true
}
```

> **注意**：将 `agent_id` 替换为第二步创建智能体后记录的实际 ID。

### 3.3 发送请求

可以通过以下方式发送：

**方式 A：使用 curl（命令行）**

```bash
curl -X POST "{BASE_URL}/api/chat/task/create" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>" \
  -d '{
    "title": "新员工培训体系设计",
    "description": "为我们公司设计一套新员工入职培训体系，包括90天成长计划、导师制度和试用期评估标准。",
    "agent_id": "<YOUR_AGENT_ID>",
    "execution_mode": "balanced",
    "sync": true
  }'
```

**方式 B：使用 Python**

```python
import requests

resp = requests.post(
    f"{BASE_URL}/api/chat/task/create",
    headers={
        "Content-Type": "application/json",
        "Authorization": f"Bearer {ACCESS_TOKEN}",
    },
    json={
        "title": "新员工培训体系设计",
        "description": "为我们公司设计一套新员工入职培训体系，包括90天成长计划、导师制度和试用期评估标准。",
        "agent_id": YOUR_AGENT_ID,
        "execution_mode": "balanced",
        "sync": True,
    },
)
print(resp.json())
```

### 3.4 查看执行流程

任务执行的完整链路如下：

```
用户输入培训相关任务
  → SkillSelector（LLM）判断任务与 corporate-training-designer 技能匹配
  → enrich_context_with_skill() 将完整的 SKILL.md 内容注入系统提示词
  → Agent 获得培训领域专业知识（需求分析、课程设计、TTT、领导力发展等）
  → LLM 基于技能知识生成专业的企业培训方案
```

## 第四步：验证结果

### 4.1 必检项

逐项检查以下内容，确保技能生效：

| # | 检查项 | 如何验证 |
|---|--------|---------|
| 1 | 技能已加载 | 调用 `GET /api/skills/`，确认 `corporate-training-designer` 在列表中 |
| 2 | Agent Skills 字段配置正确 | 打开 Agent 详情，确认 `skills` 字段包含 `corporate-training-designer` |
| 3 | 任务匹配到技能 | 查看任务执行日志（trace），确认 `selected_skill` 为 `corporate-training-designer` |
| 4 | 回复具备专业知识 | 检查 Agent 回复中是否包含培训需求分析、ADDIE 模型、柯氏评估等专业方法论术语 |
| 5 | 回复结构完整 | 方案应包含可衡量的培训目标、具体的学习路径、评估方案，而非泛泛的建议 |
| 6 | 技能不误触发 | 发送一个与培训无关的任务（如"写一个 Python 排序算法"），确认技能未被注入，Agent 正常处理非培训任务 |

### 4.2 常见问题排查

| 问题 | 可能原因 | 解决办法 |
|------|---------|---------|
| 技能不在列表中 | Skill 文件未正确部署 | 检查容器内 `/root/.xagent/skills/corporate-training-designer/SKILL.md` 是否存在；执行 `POST /api/skills/reload` 重新加载 |
| Agent 回复不像培训专家 | Skills 字段未填写或填写错误 | 检查 Agent 配置中 `skills` 是否包含 `corporate-training-designer`（注意名称必须完全一致） |
| 任务没有触发技能匹配 | 任务描述与培训领域关联太弱 | 在任务描述中加入明确的培训相关关键词（如"培训方案"、"课程设计"、"讲师培养"等） |
| 技能被错误触发（非培训任务也匹配） | LLM 判断偏差 | 这是选择器行为，通常不影响结果；如需严格控制，可在 Instructions 中明确说明何时使用技能 |
| 技能内容未完整注入 | 技能内容过大超出上下文限制 | `corporate-training-designer` 约 4856 字符，通常在上下文中仅占 ~1500 tokens，不会导致此问题 |

## 第五步：进阶用法

### 5.1 多技能组合

可以在同一个 Agent 中配置多个技能，形成复合能力。例如：

```
Skills: corporate-training-designer, presentation-generator
```

当用户任务同时涉及培训方案设计和演示文稿生成时，系统会分别匹配对应技能。

### 5.2 技能 + 知识库组合

结合 xAgent 的知识库（Knowledge Base）功能，可以将企业内部的真实案例、培训资料、讲师手册等文档导入知识库，与技能配合使用：

1. 上传培训资料到知识库
2. 在 Agent 配置 `knowledge_bases` 中添加该知识库
3. Agent 将同时具备培训领域方法论（技能）和企业真实资料（知识库）

### 5.3 批量部署更多技能

如需部署全部 216 个 agency-agents-zh 技能，将整个 `skills/` 目录拷贝到容器中：

```bash
docker cp D:\github\xagent\docs\agency-agents-zh\skills\. xagent_backend:/root/.xagent/skills/
```

然后执行 reload：

```bash
curl -X POST "{BASE_URL}/api/skills/reload" \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>"
```

## 快速操作清单（Cheatsheet）

```
□ Step 1: 确认技能已加载
  □ GET /api/skills/ 确认 corporate-training-designer 在列表中
  □ 如不在，检查文件部署并执行 POST /api/skills/reload

□ Step 2: 创建 Agent
  □ 打开 {BASE_URL}/agents
  □ 填写 Name: 企业培训课程设计师
  □ 粘贴 Instructions（含工作流程和沟通风格）
  □ 设置 Skills: corporate-training-designer
  □ 设置 Execution Mode: balanced
  □ 添加 Suggested Prompts
  □ 保存, 记录 agent_id

□ Step 3: 测试调用
  □ 在 Agent 对话界面发送培训相关任务
  □ 验证回复包含专业培训方法论和结构化方案
  □ 或通过 POST /api/chat/task/create 调用

□ Step 4: 验证
  □ Skills 列表中有 corporate-training-designer
  □ Agent skills 字段包含 corporate-training-designer
  □ 任务 trace 中 selected_skill = corporate-training-designer
  □ Agent 回复包含培训领域专业知识（ADDIE、柯氏评估、TTT 等）
  □ 非培训任务不会触发技能（技能隔离正常）
```

## 技能核心能力速览

| 能力域 | 覆盖内容 |
|--------|---------|
| **培训需求分析** | 组织诊断、胜任力差距分析、BEI 访谈法、培训 ROI 预估、需求优先级排序 |
| **课程体系设计** | ADDIE 模型、SAM 模型、学习路径规划、能力模型映射、课程分类体系 |
| **教学设计方法论** | 布鲁姆分类法、建构主义、翻转课堂、混合式学习 OMO、体验式学习、游戏化学习 |
| **企业学习平台** | 钉钉学堂、企业微信学习、飞书知识库、UMU、云学堂、酷学院 |
| **内容开发** | 微课制作（5-15min）、案例教学、沙盘模拟、剧本杀式培训、课程包标准化、经验萃取 |
| **讲师培养 TTT** | 内训师选拔、授课技巧、课件开发标准、讲师认证体系、讲师社群运营 |
| **新员工培训** | 入职 SOP、文化融入、导师制 Buddy System、90 天成长计划、试用期评估 |
| **领导力发展** | 管理梯队建设、HIPO 高潜培养、行动学习、360 度反馈、继任者计划 |
| **培训评估** | 柯氏四级评估（反应→学习→行为→结果）、学习数据分析、数据看板 |
| **合规培训** | 信息安全、反腐败、数据隐私（PIPL）、安全生产、全员覆盖与记录存档 |
